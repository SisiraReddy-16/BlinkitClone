# Blinkit Landing Page Clone

A responsive clone of the Blinkit landing page built using HTML and CSS.

## 🚀 Features

- Responsive design for desktop and mobile
- Modern UI inspired by Blinkit
- Clean layout using Flexbox/CSS
- Mobile-friendly navigation and sections

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📱 Responsive Design

The website adjusts automatically for:
- Desktop screens
- Tablets
- Mobile devices
